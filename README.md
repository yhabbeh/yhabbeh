## 🚀 About Me

I'm a **Software Engineer specialized in Flutter development**, focused on turning complex requirements into clean, maintainable, and high-performance applications.

My work revolves around:

* 📱 Building cross-platform applications with **Flutter & Dart**
* 🧱 Designing maintainable architectures and reusable components
* 🔄 Implementing scalable state management with **BLoC / Cubit**
* 🌐 Integrating **REST APIs, JSON, Firebase and third-party services**
* 🔐 Building applications with security and data privacy in mind
* 🤖 Exploring **Artificial Intelligence and Machine Learning**
* 👨‍🏫 Sharing knowledge through **technical training and mentoring**
* 🚀 Continuously improving development workflows, architecture and performance

I enjoy working on products where software has a real-world purpose — from **banking and healthcare applications to educational and AI-focused projects**.
